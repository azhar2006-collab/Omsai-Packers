# OM SAI Packers and Movers

A responsive, static business website built with HTML5, CSS3 and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. There are no build steps, package installs or backend services.

## Project files

- `index.html` — semantic page structure, SEO metadata, local business schema and page content.
- `css/style.css` — responsive layouts, typography, colors, motion and interaction states.
- `js/script.js` — service and gallery cards, mobile navigation, form validation, WhatsApp handoff and lightbox.
- `images/logo.png` — the latest logo artwork supplied by the business owner, with a transparent background.
- `WhatsApp Image 2026-11-13 at 3.58.45 PM.jpeg` — supplied visiting card reference.

## Enquiries

The enquiry forms validate the required details and open a prefilled WhatsApp message for **+91 84381 58047**. The customer reviews and sends that message in WhatsApp. The site does not claim that a message has been delivered or stored.

## Images and reviews

Moving and service photography is loaded from Unsplash's image CDN. A network connection is needed to display those remote images. Gallery items are explicitly described as illustrative. Review cards are clearly marked sample placeholders; replace them with customer feedback only after receiving permission to publish it.

## Before launch

Confirm the business address, service availability and contact details; add a privacy notice if required; test the WhatsApp links on mobile and desktop; and replace sample review cards with approved customer quotes or remove that section.
